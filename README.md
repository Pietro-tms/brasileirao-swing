# ⚽ Gerador e Classificador de Campeonato de Futebol

Projeto desenvolvido em Java Swing que simula partidas entre times de futebol, gerando confrontos aleatórios e organizando os resultados em uma tabela de classificação.

## 📋 Funcionalidades

- Geração automática de partidas entre equipes.
- Simulação de resultados aleatórios.
- Atualização automática das estatísticas dos times.
- Geração de tabela de classificação.
- Ordenação personalizada por diferentes critérios:
  - Pontos
  - Vitórias
  - Saldo de gols
  - Gols marcados
  - Derrotas
  - Outros critérios implementados no projeto
